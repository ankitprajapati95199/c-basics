## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/<ankitprajapati95199>/c-basics.git
cd c-basics
```

### 2️⃣ Compile with GCC

```bash
# Example: program01.c
gcc program01.c -o program01
```

### 3️⃣ Run the program

| Platform | Command |
|----------|---------|
| 🪟 Windows | `.\program01.exe` |
| 🐧 Linux / 🍎 macOS | `./program01` |
